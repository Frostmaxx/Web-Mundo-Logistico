# Mundo Logístico - Sitio Web

Sitio web estático para Mundo Logístico, empresa de soluciones integrales de transporte y logística en Venezuela.

## Estructura

```
Web Mundo Logistico/
├── index.html       # Página principal
├── nosotros.html     # Sobre nosotros
├── servicios.html    # Servicios ofrecidos
├── css/
│   └── style.css    # Estilos
├── resources/       # Imágenes y recursos
│   ├── fleet/       # Imágenes de flota
│   └── clientes/    # Logos de clientes
├── script.js        # JavaScript
├── robots.txt       # SEO
├── sitemap.xml      # Mapa del sitio
└── .htaccess        # Configuración Apache
```

## Deploy en cPanel

### Configuración

1. En cPanel → **Domains** → **Create A New Domain**
2. Domain: `mundologistico.com`
3. Document Root: `/home/amertrhr/mundo_logistico_web/`

### Pasos

1. Crear carpeta: `mundo_logistico_web/`
2. Subir archivos a `/home/amertrhr/mundo_logistico_web/`
3. Asegurar que `.htaccess` esté presente
4. Configurar SSL desde cPanel
5. Probar el sitio
